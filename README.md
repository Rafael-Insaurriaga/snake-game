# 🐍 Snake Game

Jogo em Python + pygame que mistura o clássico jogo da cobrinha com o movimento livre do Slither.io. Coma maçãs, cresça e evite as paredes e o próprio corpo.

## Como jogar

| Tecla | Ação |
|---|---|
| ← ↑ ↓ → | Direcionar a cobra |
| Espaço | Dash (acelera) |
| R | Reiniciar após o Game Over |

## Como rodar

Requisitos: Python 3 e pygame.

```bash
git clone https://github.com/Rafael-Insaurriaga/snake-game.git
cd snake-game
pip install pygame
python main.py
```
